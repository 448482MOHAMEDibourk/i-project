# ai-school — Local LLM integration scaffold

This scaffold provides foundation files to integrate local models via Ollama and Aider.

Structure

- `README.md` — this file
- `setup.md` — setup instructions
- `clients/` — small Python client wrappers for Ollama and Aider
- `scripts/` — demo runner and helper scripts
- `tests/` — minimal unit tests
- `requirements.txt` — Python dependencies

Goals

- Provide clear steps to run local LLMs using Ollama and Aider
- Provide simple Python wrappers and a demo runner
- Make it easy to extend for your ai-school project
